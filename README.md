# 📊 Netflix Data Analysis

This project is a comprehensive analysis of Netflix's content dataset using Python and popular data science libraries. The goal is to extract insights related to the type, genre, release trends, and distribution of Netflix titles.

## 🔍 Project Highlights

- **Data Preprocessing**:
  - Handled null values, duplicates, and date formatting.
  - Cleaned and prepared the data for analysis.

- **Exploratory Data Analysis (EDA)**:
  - Identified the distribution of Movies vs TV Shows.
  - Analyzed trends in content release over years and months.
  - Most frequent genres, top directors, and content by country.
  - Insights into rating systems and content duration.

- **Visualizations**:
  - Created informative charts using Matplotlib and Seaborn.
  - Visual representation of key findings for better clarity.


## 🛠️ Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
